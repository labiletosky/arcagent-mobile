# ArcAgent

Decentralized commerce and escrow platform built on Arc.

## Features
- USDC escrow payments
- Buyer/seller order flow
- Smart contract settlement
- Circle Wallet integration
- Mobile-first experience

## Live Demo

## Built With
- Arc
- USDC
- Circle
- React/Vite
- Solidity
